
# STM32 CubeMX Makefile-Based Advanced Build System

This project extends the Zephyr-style build approach for STM32 CubeMX generated firmware.
It allows you to assemble Makefile-based autogenerated projects, add your own code, and build with CMake.
It works in VS Code and includes a solid Menuconfig workflow that makes projects more flexible and easier to maintain.

## Features

- CMake-based build system
- Integrated Menuconfig support
- Manual and Makefile-configured build flow
- Cross-platform support
- SEGGER debugger support
- RTT debug logging in the VS Code console
- ST-Link debug logging in the VS Code console

## Deployment

Run the following commands:

```bash
git clone https://github.com/fillbert/CubeMX2CMake.git
cd CubeMX2CMake
chmod 0777 env_setup.sh
source ./env_setup.sh
```

If the setup is not completed on the first run, execute it again:

```bash
source ./env_setup.sh
```

Open the project in VS Code:

```bash
code .
```

In VS Code:

- Press `Ctrl+Shift+B` and select `Build - DEBUG` or `Build - RELEASE`
- Select the proper launch configuration and start debugging

## Usage Example

- Create an initial project in CubeMX and configure all hardware that must be initialized before your application logic runs
- Save the generated project in the repository root (as in the provided examples)
- Configure CubeMX code generation to produce a Makefile-based project
- Generate code and close CubeMX

Then override the default task code so your user logic is separated from Cube-generated sources:

```c
void StartDefaultTask(void const * argument)
{
  /* init code for USB_DEVICE */
  MX_USB_DEVICE_Init();

  /* USER CODE BEGIN 5 */
  /* Infinite loop */
  for (;;)
  {
    extern void userCoreInit(void);
    userCoreInit();
    osThreadSuspend(NULL);
  }
  /* USER CODE END 5 */
}
```

For CMake-based projects, avoid using file globbing for source discovery.
The recommended approach is to add a `CMakeLists.txt` file in each directory and list source files explicitly.
This gives you fine-grained control over build inclusion and makes it easy to exclude files through Menuconfig options.
